# pharmacovigilance and benefits agents, while all four integrity locks recorded the same tree hash
# and every CI run was green. For a benefits determination workflow the missing control is a
# due-process risk: a retried or replayed finalize writes a second COMMITTED record, i.e. an adverse

# person, with two notice clocks and two appeal windows the agency cannot reconcile.
#

#
#   pip install --require-hashes -r requirements-core.txt
#
