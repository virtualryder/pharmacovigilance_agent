# Regenerating `.secrets.baseline`

The baseline is **environment-dependent**. Two things must match the CI runner or the BLOCKING
secret gate fails on findings that are not new:

1. **The scanner version.** `detect-secrets` writes its version into the baseline and different
   versions find different things. `tests/test_secrets_baseline_pin.py` fails the suite if the
   committed baseline's version differs from the pin in `.github/workflows/security.yml`.
2. **The checked-out content.** A Windows working tree is CRLF; the runner checks out LF. Tokens
   at end of line hash differently, so a baseline generated in a Windows working tree disagrees
   with the runner on exactly those findings.

Both were true on 2026-09-08: the baselines had been generated by 1.5.50 on a CRLF tree while CI
pinned 1.5.0 on an LF checkout, and the gate went red on all four packs the first time it was
able to run at all.

## The procedure

Regenerate **inside a fresh clone**, on Linux, with the pinned version — that is the runner's
environment, reproduced:

```bash
pip install "detect-secrets==1.5.0"          # must equal the pin in security.yml
git clone --no-hardlinks /path/to/<pack> /tmp/rebaseline && cd /tmp/rebaseline
detect-secrets scan --baseline .secrets.baseline      # rescans IN PLACE, keeps reviewed findings
cp .secrets.baseline /path/to/<pack>/.secrets.baseline
```

Write the file as UTF-8 **without a BOM** and with LF line endings. A PowerShell redirect
(`detect-secrets scan > .secrets.baseline`) produces UTF-16LE, which detect-secrets cannot read —
that is how three packs ended up with a secret-detection step that compared nothing.

## Reviewing before you commit

Every finding a rescan adds must be read before it is accepted. The baseline is a record that a
human looked at each hit and judged it a fixture, an environment-variable name, a public digest or
a documented placeholder — not a credential. `tools/check_secrets_baseline.py` prints exactly what
is new; a re-baseline commit should say WHY each addition is not a secret.

## Verifying the way CI does

```bash
cp .secrets.baseline /tmp/committed.json
detect-secrets scan --baseline .secrets.baseline
python tools/check_secrets_baseline.py /tmp/committed.json .secrets.baseline   # must exit 0
```
